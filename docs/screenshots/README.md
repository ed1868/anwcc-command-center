# Screenshots

Drop the images below into this folder using the **exact filenames**. They're
already referenced from [`../../README.md`](../../README.md) and
[`../FEATURES.md`](../FEATURES.md), so they'll appear automatically once the
files are here.

**Capture all of these from the running app at http://localhost:3100** (start it
with `./scripts/dev-up.sh`, click **VOICE**, and allow the mic). Use PNG.

| Filename | What to capture |
|---|---|
| `jarvis-core.png` | The amber particle-core HUD while Jarvis is speaking (status readout + live transcript visible). |
| `camera-wall.png` | The multi-camera surveillance grid — e.g. after *"Put Miami, Times Square, and Tokyo on the wall."* |
| `traffic-cams-map.png` | Traffic-camera markers blanketing the map over LA — after *"Show me traffic cameras in LA."* |
| `flights.png` | Live aircraft over a region — after *"Show me all air traffic"* or *"What flights are over Florida?"* |
| `annotations.png` | A country outlined on the map — e.g. after *"Outline Taiwan."* |

Tips:
- Shoot at a wide viewport (≥1440px) so the map and HUD both read well.
- For `jarvis-core.png`, grab the frame mid-sentence so the core is lit and the
  transcript line is populated.
